## 二、修复方案

### 方案1: 提取公共组件/Mixin（推荐）

**目标**: 消除 190 行重复代码

**实施步骤**:

#### 步骤1: 创建 `DmHistoryMixin.js`

提取公共逻辑：
- `renderDiff()`
- `formatXml()`
- `formatSide()`
- `getVersionTypeColor()`
- `getVersionTypeName()`

#### 步骤2: 创建 `DmVersionSlots.vue` 组件

提取公共插槽模板：
- 锁定状态图标
- 版本号渲染
- 版本类型标签
- 版本日期处理

#### 步骤3: 重构两个文件

引用 mixin 和组件，删除重复代码

**预期效果**:
- 代码行数减少 ~180行/文件
- 单元测试只需覆盖一处
- Bug 修复只需改一处

---

### 方案2: 统一为单一组件（备选）

**目标**: 合并为一个组件，通过 props 控制展示模式

**优点**: 彻底消除重复  
**缺点**: 组件复杂度增加，路由需要调整

**不推荐**: 当前两种使用场景差异较大（弹框 vs 独立页面）

---

### 方案3: 字段名统一

**目标**: 统一使用 `issueNo-inWork` 组合

**实施**:
1. 代码注释明确 `issueNo` = issue number, `inWork` = in-work issue
2. 路由传参统一使用 `issueNo` 和 `inWork` 分开传递
3. 避免使用模糊的 `version` / `versionCode` 命名

---

### 方案4: 大文档性能保护

**目标**: 对比前检测文档大小

**实施**:
```javascript
handleCompare() {
  // ... 现有逻辑
  
  // 添加大小检测
  const size0 = new Blob([this.orig0]).size
  const size1 = new Blob([this.orig1]).size
  const totalMB = (size0 + size1) / 1024 / 1024
  
  if (totalMB > 4) {
    this.$confirm({
      title: '大文档警告',
      content: `两个版本总大小为 ${totalMB.toFixed(1)}MB，对比可能较慢。是否继续？`,
      onOk: () => this.renderDiff(this.orig0, this.orig1)
    })
    return
  }
  
  this.renderDiff(this.orig0, this.orig1)
}
```
