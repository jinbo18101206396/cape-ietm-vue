🔧 上标/下标预览修复验证

修复说明：

问题：后端XSLT未处理 <superScript>/<subScript>/<emphasis> 标签，导致预览时显示为普通文本。

解决：在 DmPreviewModal.vue 的 show() 方法中添加标签转换逻辑，将XML标签转换为HTML标签。

测试用例 1: 上标显示 ✓ 已修复

设计视图输入：
1²
XML源码：
<para>1<superScript>2</superScript></para>
修复前预览显示（❌ 错误）：
12
修复后预览显示（✓ 正确）：
12

测试用例 2: 下标显示 ✓ 已修复

设计视图输入：
H₂O
XML源码：
<para>H<subScript>2</subScript>O</para>
修复前预览显示（❌ 错误）：
H2O
修复后预览显示（✓ 正确）：
H2O

测试用例 3: 加粗显示 ✓ 已修复

设计视图输入：
这是重要内容
XML源码：
<para>这是<emphasis>重要</emphasis>内容</para>
修复前预览显示（可能正常或错误）：
这是重要内容
修复后预览显示（✓ 正确）：
这是重要内容

测试用例 4: 混合格式 ✓ 已修复

设计视图输入：
公式： x² + y² = z²
XML源码：
<para><emphasis>公式：</emphasis> x<superScript>2</superScript> + y<superScript>2</superScript> = z<superScript>2</superScript></para>
修复前预览显示（❌ 错误）：
公式： x2 + y2 = z2
修复后预览显示（✓ 正确）：
公式： x2 + y2 = z2

代码实现

DmPreviewModal.vue - show() 方法修复代码：
// 修复文本格式显示：将S1000D XML标签转换为HTML标签 // 原因：后端XSLT可能未完整处理这些内联格式标签 body = body .replace(/<superScript>/g, '<sup>') .replace(/<\/superScript>/g, '</sup>') .replace(/<subScript>/g, '<sub>') .replace(/<\/subScript>/g, '</sub>') .replace(/<emphasis>/g, '<strong>') .replace(/<\/emphasis>/g, '</strong>')
