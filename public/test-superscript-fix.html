🔍 修复的CSS代码

/* 上标和下标样式 */
sup {
  vertical-align: super;  /* 垂直位置提升 */
  font-size: 0.75em;      /* 字体缩小到75% */
  line-height: 0;         /* 不影响行高 */
}

sub {
  vertical-align: sub;    /* 垂直位置下降 */
  font-size: 0.75em;      /* 字体缩小到75% */
  line-height: 0;         /* 不影响行高 */
}

📝 如何验证修复

  1. 打开 DM 编辑页面，点击"预览"按钮
  2. 在预览弹出框中，观察包含上标的文本
  3. 上标应该显示为：字体更小且位置上移
  4. 如果仍显示为普通文本，请按 Ctrl+Shift+R 强制刷新浏览器
