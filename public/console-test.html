🔍 Console 清理验证测试

说明

这个页面用于测试 console 清理配置是否生效：

  • 开发环境： 所有 console 都应该输出
  • 生产环境： 只有 error 和 warn 应该输出

测试按钮

打开浏览器控制台，然后点击下面的按钮：

console.log('这是 log 消息 - 生产环境应该被移除')
console.info('这是 info 消息 - 生产环境应该被移除')
console.debug('这是 debug 消息 - 生产环境应该被移除')
console.warn('这是 warn 消息 - 所有环境都应该保留')
console.error('这是 error 消息 - 所有环境都应该保留')

预期结果

开发环境（npm run serve）：

  • ✓ 所有 5 种 console 都会在控制台显示

生产环境（npm run build 后）：

  • ✗ console.log - 不显示
  • ✗ console.info - 不显示
  • ✗ console.debug - 不显示
  • ✓ console.warn - 显示
  • ✓ console.error - 显示

验证步骤

  1. 开发环境测试：
    npm run serve
    在浏览器打开，点击测试按钮，应该能看到所有输出
  2. 生产环境构建：
    npm run build
  3. 验证构建结果：
    grep -r "console\.log" dist/js/
    应该没有或极少匹配（部分第三方库可能有）
  4. 部署测试：
    • 部署 dist 目录到服务器
    • 打开浏览器控制台
    • 点击测试按钮
    • 应该只看到 warn 和 error
