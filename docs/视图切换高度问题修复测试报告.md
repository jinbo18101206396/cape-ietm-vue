## 缺陷描述

### 问题现象
在设计视图页面，点击"源码视图"按钮进入源码视图页面后，**中间XML内容编辑区的高度缩小了**。

### 复现步骤
1. 打开DM编辑器（编辑模式）
2. 点击para行的铅笔图标 → 进入设计视图
3. 观察UEditor高度（正常占满）
4. 点击底部"源码视图"页签 → 切换回源码视图
5. **问题**：CodeMirror编辑器高度异常缩小

### 影响范围
- **严重程度**: 高 - 影响核心编辑功能
- **影响用户**: 所有使用设计视图功能的用户
- **影响场景**: 设计视图 ↔ 源码视图切换

## 根因分析

### 1. CSS结构缺陷

**问题代码**：
```html
<!-- DmContentEditor.vue 第28行 -->
<div class="design-view-container">  <!-- ❌ 无CSS定义 -->
  <para-designer />
</div>
```

**CSS缺失**：
```css
/* ❌ 完全没有 .design-view-container 的样式定义 */
```

**对比源码视图**：
```css
/* ✅ source-pane有完整的flex布局 */
.source-pane {
  flex: 1;
  min-height: 0;
  display: flex;
  flex-direction: column;
}
```

### 2. Flex高度链断裂

**DOM结构**：
```
.view-tabs (flex: 1)
  └─ .ant-tabs-content (flex: 1, min-height: 0)
      └─ .ant-tabs-tabpane-active (height: 100%, display: flex)
          ├─ .design-view-container (❌ 无flex定义)
          │   └─ .para-designer (height: 100%)
          │       └─ UEditor (initialFrameHeight: window.innerHeight - 180)
          │
          └─ .source-pane (✅ flex: 1, display: flex)
              └─ dm-source-view (height: 100%)
                  └─ CodeMirror (height: 100%)
```

**问题分析**：
1. `.design-view-container` 没有 `flex: 1`，无法撑满父容器
2. `.para-designer` 使用 `height: 100%`，参照的是错误的父容器高度
3. UEditor使用固定高度 `window.innerHeight - 180`
4. 切换回源码视图时，CodeMirror继承了错误的高度计算

### 3. 切换时未强制刷新

**原有代码**：
```javascript
// DmContentEditor.vue 第733行
onViewTabChange(key) {
  this.viewMode = key
  if (key === 'source') {
    this.paraDesignerVisible = false
    this.treeVisible = true
    // ❌ 没有强制CodeMirror重新计算高度
  }
}
```

## 修复方案

### 修复1: 添加design-view-container的flex样式

**位置**: `DmContentEditor.vue` 第1919行之后

**修复代码**：
```css
/* 设计视图页签内容：与源码视图对称，ParaDesigner占满容器 */
.design-view-container {
  flex: 1;              /* 占据剩余空间 */
  min-height: 0;        /* 防止flex子元素撑开父容器 */
  display: flex;        /* 启用flex布局 */
  flex-direction: column; /* 垂直排列 */
}
```

### 修复2: 切换时强制CodeMirror刷新

**位置**: `DmContentEditor.vue` 第733行

**修复代码**：
```javascript
onViewTabChange(key) {
  this.viewMode = key
  if (key === 'source') {
    this.paraDesignerVisible = false
    this.treeVisible = true
    if (!this.readonly) {
      this.attrVisible = true
    }

    // ✅ 修复：强制CodeMirror重新计算高度
    this.$nextTick(() => {
      if (this.$refs.editor && this.$refs.editor.getEditor()) {
        this.$refs.editor.getEditor().refresh()
      }
    })
  }
}
```

    })
  }

  return results
