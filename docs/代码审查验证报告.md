### 修复2: 切换时强制CodeMirror刷新

**修复代码**：
```javascript
// DmContentEditor.vue onViewTabChange方法
onViewTabChange(key) {
  this.viewMode = key
  if (key === 'source') {
    this.paraDesignerVisible = false
    this.treeVisible = true
    if (!this.readonly) {
      this.attrVisible = true
    }

    // ✅ 新增：强制CodeMirror重新计算高度
    this.$nextTick(() => {
      if (this.$refs.editor && this.$refs.editor.getEditor()) {
        this.$refs.editor.getEditor().refresh()
      }
    })
  }
}
```

## 4️⃣ 潜在风险分析

### 风险1: $nextTick时序 ⚠️ 低风险

**描述**: $nextTick可能在某些极端情况下不够

**分析**:
- $nextTick等待Vue的DOM更新队列完成
- 对于CodeMirror这种第三方组件，通常足够
- CodeMirror.refresh()本身是同步操作

**缓解措施**: 
- 已在代码中添加防御性检查：`if (this.$refs.editor && this.$refs.editor.getEditor())`
- 如果仍有问题，可以添加setTimeout(fn, 0)作为后备

**评估**: ⚠️ 低风险，实际使用中很少遇到
