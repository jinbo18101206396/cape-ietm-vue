## 二、修复内容回顾

### 2.1 问题描述

**错误1**: 源码视图→设计视图时报`XML格式错误：找不到 </para> 结束标签（行70）`  
**错误2**: 设计视图保存时报`保存失败：内部错误：endline(-1) < lineno(69)`  

### 2.2 根本原因

**文件**: `ParaDesigner.vue` 第405行  
**缺陷**: `if (closingTagIdx > -1 && beginidx === indentIdx)`  
**问题**: 严格要求开始标签和结束标签缩进完全相等  
**场景**: 用户手动编辑、格式化工具、左对齐风格会产生缩进不一致  

### 2.3 修复方案

**修复11**: 两轮匹配策略
- 第一轮：`indentIdx <= beginidx`（允许结束标签左对齐）
- 第二轮：放弃缩进检查，只匹配标签名（兜底机制）

**修复12**: 改进错误消息
- 显示用户实际点击的行号 + 开始标签行号
- 提供更准确的诊断信息

## 五、问题发现与修复

### 5.1 测试中发现的问题

**无新问题发现**

在L1单元测试和L4代码排查中，未发现新的P0/P1级别问题。

### 5.2 已知限制

1. **兜底匹配的风险**：如果XML存在非法的para嵌套，兜底匹配可能选择错误的结束标签
   - **缓解措施**：S1000D标准不允许para嵌套，XSD校验在§17.2已实现
   - **影响范围**：极低（非法XML应在校验阶段被拦截）

2. **大文档性能**：10,000行的DM，两轮遍历可能需要20ms
   - **实测性能**：可接受范围
   - **优化建议**：后续可考虑缓存机制
