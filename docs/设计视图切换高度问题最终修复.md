# 设计视图切换高度问题 - 最终修复方案

**问题**: 初次加载正常，从设计视图切换到源码视图时CodeMirror高度缩小  
**修复日期**: 2026-09-23  
**修复状态**: ✅ 已完成并编译通过

---

## 🎯 **问题本质**

**初次加载** ✅ 正常 → **从设计视图切换** ❌ 异常

这说明问题不在CodeMirror本身，而在**Ant Design Tabs组件的CSS配置**。

---

## 🔴 **根本原因**

### CSS选择器不完整

**修复前的CSS**（只设置active状态）：
```less
.view-tabs /deep/ .ant-tabs-tabpane-active {
  height: 100%;
  display: flex;
  flex-direction: column;
}
```

### 问题场景

**初次加载（正常）**：
```
页面加载 → 源码视图默认激活 
→ .ant-tabs-tabpane 立即获得 .ant-tabs-tabpane-active 类
→ CSS样式立即生效 → ✅ 高度正常
```

**切换时（异常）**：
```
点击"源码视图"按钮
→ .ant-tabs-tabpane 先显示（❌ 无flex布局）
→ 然后才添加 .ant-tabs-tabpane-active 类（✅ 有flex布局）
→ CodeMirror在中间状态计算高度 → ❌ 高度错误
```

---

## 🛠️ **修复方案**

### 同时设置`.ant-tabs-tabpane`和`.ant-tabs-tabpane-active`

**文件**: `DmContentEditor.vue:1947-1972`

**修复后的CSS**：
```less
/* 所有tabpane都设置flex布局 */
.view-tabs /deep/ .ant-tabs-tabpane {
  height: 100%;
  display: flex;
  flex-direction: column;
}

/* active状态（保持，虽然已被上面覆盖）*/
.view-tabs /deep/ .ant-tabs-tabpane-active {
  height: 100%;
  display: flex;
  flex-direction: column;
}
```

### 修复原理

- 不仅设置 `.ant-tabs-tabpane-active`（激活状态）
- 也设置 `.ant-tabs-tabpane`（所有状态）
- 确保切换过程中，任何时刻tabpane都有正确的flex布局
- CodeMirror无论何时计算高度，都能获取正确的容器尺寸

## 💡 **技术要点**

### CSS层叠规则

```css
/* 两个选择器的优先级相同 */
.view-tabs /deep/ .ant-tabs-tabpane { ... }          /* 所有tabpane */
.view-tabs /deep/ .ant-tabs-tabpane-active { ... }   /* 激活的tabpane */

/* .ant-tabs-tabpane-active 同时匹配两个选择器 */
/* 后者覆盖前者（如果有冲突），但这里样式相同，所以无冲突 */
```

### 为什么两个都要设置？

虽然看起来重复，但：
1. `.ant-tabs-tabpane` 确保**所有状态**都有基础布局
2. `.ant-tabs-tabpane-active` 确保**激活状态**有正确样式
3. 两者结合，覆盖Tabs切换的所有时刻
