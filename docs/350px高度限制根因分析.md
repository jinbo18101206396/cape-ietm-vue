## 🎯 **关键发现**

用户观察：**下面空白区域的高度与流程信息模块展开的高度一样**

- `workflowHeight: 350` (默认值)
- `scroll.offsetHeight: 350` (CodeMirror-scroll实际高度)

## 🐛 **问题根因推测**

### 推测1：UEditor设置了全局CSS规则

UEditor可能添加了：

```css
.CodeMirror-scroll {
  max-height: 350px !important;
}

/* 或者 */
.ant-tabs-tabpane {
  max-height: 350px;
}

/* 或者 */
.source-pane {
  max-height: 350px;
}
```

**为什么是350px？** 因为UEditor可能读取了 `workflowHeight` 的值，或者巧合地使用了相同的值。

### 推测2：ParaDesigner污染了祖先容器

ParaDesigner在初始化时，可能：

```javascript
// 设置父容器高度
document.querySelector('.view-tabs').style.maxHeight = '350px';
// 或
document.querySelector('.region-center').style.maxHeight = '350px';
```

### 推测3：UEditor的iframe影响了全局样式

UEditor使用iframe，可能在主文档中注入了style标签：

```html
<style>
  .CodeMirror-scroll {
    max-height: 350px !important;
  }
</style>
```

## 🔬 **诊断脚本（必须执行）**

### 脚本1：检查所有影响CodeMirror-scroll的CSS规则

```javascript
const cmScroll = document.querySelector('.CodeMirror-scroll');
const computed = getComputedStyle(cmScroll);

console.log('==== CodeMirror-scroll计算样式 ====');
console.log('height:', computed.height);
console.log('max-height:', computed.maxHeight);  // ← 关键！
console.log('min-height:', computed.minHeight);

// 查找所有应用的CSS规则
const allRules = [];
for (let sheet of document.styleSheets) {
  try {
    for (let rule of sheet.cssRules || sheet.rules) {
      if (rule.selectorText && rule.cssText.includes('CodeMirror-scroll')) {
        allRules.push({
          selector: rule.selectorText,
          cssText: rule.cssText,
          href: sheet.href || 'inline'
        });
      }
    }
  } catch (e) {}
}
console.log('==== 所有CodeMirror-scroll规则 ====');
console.table(allRules);
```

## 🛠️ **修复方案**

### 方案：在切换时移除所有包含350px的CSS规则

```javascript
onViewTabChange(key) {
  if (key === 'source') {
    // ...现有代码

    // ✅ 新增：移除所有可疑的CSS规则
    this.$nextTick(() => {
      // 1. 移除动态添加的style标签
      document.querySelectorAll('style').forEach(style => {
        const content = style.textContent || style.innerHTML;
        if (content.includes('CodeMirror-scroll') || 
            content.includes('350px')) {
          console.warn('[修复] 移除可疑样式:', content.substring(0, 100));
          style.remove();
        }
      });

      // 2. 强制清理所有祖先容器的max-height
      let el = this.$el.querySelector('.CodeMirror-scroll');
      while (el && el !== this.$el) {
        el.style.maxHeight = '';
        el = el.parentElement;
      }

      // 3. 然后再执行现有的刷新逻辑
      // ...
    });
  }
}
```
