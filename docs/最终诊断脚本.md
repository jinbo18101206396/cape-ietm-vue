# CodeMirror高度问题 - 最终总结和解决方案

## 📊 **问题现状**

### 确认的事实

1. **初次加载（正常）**：
   - CodeMirror容器高度：574px
   - CodeMirror-scroll高度：624px
   - 显示正常（约85行）

2. **从设计视图切换后（异常）**：
   - CodeMirror容器高度：574px（正常）
   - CodeMirror-scroll高度：350px（被限制）
   - clientHeight：300px（被限制）
   - 显示异常（约69行）

3. **关键观察**：
   - 用户发现"下面空白区域的高度与流程信息模块展开的高度一样"
   - `workflowHeight = 350px`（正好是scroll被限制的高度）

### 尝试过的修复（均失败）

- ✗ 清理内联样式
- ✗ 重置CodeMirror内部缓存
- ✗ 清理祖先容器样式

- ✗ 删除动态style标签（导致样式错乱）

### 未解之谜

- 不是内联样式（清理无效）
- 可能是CSS规则（但无法定位）
