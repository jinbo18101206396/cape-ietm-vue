## 📝 技术细节

### 方法说明: getJumpableNodes

**作用**: 获取当前节点可以跳转到的节点列表

**参数**:
- `record` - 当前节点对象

**返回值**: 
```javascript
[
  { value: '_clientId_1', label: '创建节点' },
  { value: '_clientId_2', label: 'DM编写' },
  { value: '_clientId_3', label: '审核' },
  { value: '_clientId_4', label: '批准' }
]
```

**逻辑**:
1. 过滤掉当前节点自身（避免自己跳转到自己）
2. 将剩余节点映射为 `{ value, label }` 格式
3. `value` 使用 `_clientId`（前端稳定标识符）
4. `label` 只使用 `nodename`（节点名称）

### 为什么使用 _clientId 而不是 seqno

- `_clientId` 是前端为每个节点生成的唯一标识符
- 用户可以修改 `seqno`（顺序号），会导致值变化
- `_clientId` 在整个编辑过程中保持稳定
- 提交时后端会将 `_clientId` 映射到真实节点ID
