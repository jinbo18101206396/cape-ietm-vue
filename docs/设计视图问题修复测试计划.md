## 🔧 **修复详情**

### 修复1：问题2 - 数据丢失BUG

**文件**: `ParaDesigner.vue:364-369`

**修复前**：
```javascript
// 6. 回写CodeMirror
this.editor.replaceRange(
  xml,
  { line: this.lineno, ch: 0 },
  { line: this.endline + 1, ch: 0 }  // ❌ 多删除一行
)
```

**修复后**：
```javascript
// 6. 回写CodeMirror（精确替换para范围，避免误删后续内容）
this.editor.replaceRange(
  xml,
  { line: this.lineno, ch: 0 },
  { line: this.endline, ch: this.editor.getLine(this.endline).length }  // ✅ 精确到行尾
)
```

**修复原理**：
- `this.endline` = `</para>` 所在行号
- `ch: this.editor.getLine(this.endline).length` = 该行的字符长度（行尾）
- 精确替换 para 元素范围，不影响后续内容

### 修复2：问题3 - 自动返回源码视图

**文件**: `DmContentEditor.vue:492-495`

**修复前**：
```javascript
onParaSave() {
  this.dirty = true
  this.doSave()  // ❌ 只保存，不切换视图
}
```

**修复后**：
```javascript
async onParaSave() {
  this.dirty = true
  await this.doSave()

  // 保存成功后，自动切换回源码视图（对标旧系统行为）
  this.viewMode = 'source'
  this.paraDesignerVisible = false
  this.treeVisible = true
  if (!this.readonly) {
    this.attrVisible = true
  }

  // 强制刷新CodeMirror高度
  this.$nextTick(() => {
    if (this.$refs.editor && this.$refs.editor.getEditor()) {
      this.$refs.editor.getEditor().refresh()
    }
  })
}
```

**修复原理**：
1. 等待 `doSave()` 完成（使用 `await`）
2. 切换 `viewMode` 为 `'source'`
3. 恢复左侧树和右侧属性面板显示
4. 调用 `cm.refresh()` 确保高度正常

## 🐛 **已知限制**

1. **UEditor初始化异步性**：首次打开设计视图可能需要50-300ms加载，已有轮询机制处理
2. **公式唯一ID分配**：依赖后端 `/allocate-uniqueids` 接口，网络延迟可能影响保存速度
3. **大文档性能**：包含100+个para的文档可能在保存时有轻微延迟
