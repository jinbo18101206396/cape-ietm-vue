## ✨ 更新内容

### 🆕 新增功能

#### 1. 插入行按钮（insertrow）
- **功能**: 在当前行前快速插入空行
- **适用场景**: 编辑定义列表表格时需要添加新的术语-定义对
- **使用方法**: 
  1. 点击需要插入位置的行
  2. 点击工具栏"插入行"按钮 🔲
  3. 在新插入的空行中填写内容

**示例**：
```
原表格：
| 术语1 | 定义1 |
| 术语2 | 定义2 |  ← 点击这行
| 术语3 | 定义3 |

点击"插入行"后：
| 术语1 | 定义1 |
| 术语2 | 定义2 |
| [空行] | [空行] |  ← 新插入的行
| 术语3 | 定义3 |
```

#### 2. 删除行按钮（deleterow）
- **功能**: 快速删除当前选中的行
- **适用场景**: 编辑定义列表表格时需要删除不需要的行
- **使用方法**:
  1. 点击需要删除的行
  2. 点击工具栏"删除行"按钮 ❌
  3. 该行立即被删除

**示例**：
```
原表格：
| 术语1 | 定义1 |
| 术语2 | 定义2 |  ← 点击这行并删除
| 术语3 | 定义3 |

点击"删除行"后：
| 术语1 | 定义1 |
| 术语3 | 定义3 |
```

## 📖 用户指南

### 快速上手

#### 场景1：在表格中间插入新行

```
步骤：
1. 打开包含定义列表的Para元素
2. 点击需要插入位置的后一行
3. 点击工具栏"插入行"按钮
4. 在新插入的空行中填写术语和定义
5. 点击"保存"
```

#### 场景2：删除表格中的错误行

```
步骤：
1. 打开包含定义列表的Para元素
2. 点击需要删除的行
3. 点击工具栏"删除行"按钮
4. 确认行已删除
5. 点击"保存"
```

#### 场景3：批量调整表格结构

```
步骤：
1. 连续点击"插入行"添加多个空行
2. 或连续点击"删除行"删除多个行
3. 使用"撤销"按钮可以恢复误操作
4. 调整完成后点击"保存"
```

### 常见问题（FAQ）

**Q1: 新按钮在哪里？**  
A: 打开Para设计器后，工具栏第3组（有序/无序列表之后）有两个新按钮："插入行"和"删除行"。

**Q2: 所有表格都能用这两个按钮吗？**  
A: 这两个按钮主要用于definitionList（定义列表）表格。Para元素中不支持普通HTML表格。

**Q3: 插入行后能撤销吗？**  
A: 可以。点击工具栏的"撤销"按钮即可恢复。

**Q4: 删除行后数据能恢复吗？**  
A: 删除操作可以通过"撤销"按钮恢复，但保存后无法恢复，请谨慎操作。

**Q5: 更新后旧的DM文件会受影响吗？**  
A: 不会。本次更新只是添加新功能，不影响现有数据。所有旧的DM文件都可以正常打开和编辑。

**Q6: 为什么看不到新按钮？**  
A: 请清除浏览器缓存（Ctrl+Shift+R）。如仍未显示，请联系技术支持。

**Q7: 能在第1行前插入吗？**  
A: 可以。点击第1行后点击"插入行"，新行会插入到第1行之前。

**Q8: 删除最后1行会怎样？**  
A: 如果表格只剩1行，删除后表格可能被移除，建议至少保留1行。
