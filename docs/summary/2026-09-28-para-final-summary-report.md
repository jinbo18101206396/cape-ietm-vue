## 🐛 问题清单

### 已修复问题（2个）

#### 问题1: inserttable按钮（P0，已修复）
- **发现时间**: 2026-09-28 上午
- **根因**: 新系统添加了旧系统没有的`inserttable`按钮
- **影响**: Para中支持普通表格，违反S1000D标准
- **修复**: 移除`inserttable`按钮，html2para中删除普通table
- **状态**: ✅ 已修复已验证

#### 问题2: insertrow/deleterow按钮缺失（P1，刚修复）
- **发现时间**: 2026-09-28 下午（深度审核）
- **根因**: 旧系统有`insertrow`/`deleterow`按钮，新系统遗漏
- **影响**: 用户无法快速在definitionList中插入/删除行
- **修复**: 在ueditor.config.js中添加两个按钮
- **状态**: ✅ 已修复待验证

### 无需修复问题（1个）

#### 问题3: insertnextrow按钮缺失（P1，无需修复）
- **发现**: 旧系统注册了`insertnextrow`按钮，新系统也注册了
- **核实**: 旧系统虽然注册，但**未添加到工具栏配置**，用户看不到
- **结论**: 新系统与旧系统一致，无需修复

## 🔧 修复内容详解

### 修复文件

**文件**: `public/static/ueditor/ueditor.config.js`  
**位置**: 第35-46行  
**修改**: 12行代码（添加2行注释 + 1行按钮配置）

### 修改前后对比

#### 修改前（14个按钮）
```javascript
// 包含10个基础按钮 + 4个S1000D自定义按钮 = 14个按钮
, toolbars: [[
    'undo', 'redo', '|',
    'bold', 'italic', 'strikethrough', 'superscript', 'subscript', '|',
    'insertorderedlist', 'insertunorderedlist', '|',
    // 🔥 移除inserttable按钮（对标旧系统：Para中不支持普通表格）
    // S1000D自定义按钮（对标旧系统）
    'deflist', 'interrefbutton', 'dmrefbutton', 'symbolbutton'
]]
```

#### 修改后（16个按钮）
```javascript
// 包含10个基础按钮 + 2个表格行操作按钮 + 4个S1000D自定义按钮 = 16个按钮
, toolbars: [[
    'undo', 'redo', '|',
    'bold', 'italic', 'strikethrough', 'superscript', 'subscript', '|',
    'insertorderedlist', 'insertunorderedlist', '|',
    // 🔧 添加insertrow/deleterow按钮（对标旧系统第162行）
    'insertrow', 'deleterow', '|',
    // 🔥 移除inserttable按钮（对标旧系统：Para中不支持普通表格）
    // S1000D自定义按钮（对标旧系统）
    'deflist', 'interrefbutton', 'dmrefbutton', 'symbolbutton'
]]
```

### 技术说明

1. **insertrow/deleterow是UEditor内置命令**，无需在ParaDesigner.vue中注册
2. **ParaDesigner.vue已注册insertnextrow**（第285-293行），但不在工具栏中（与旧系统一致）
3. **工具栏按钮顺序**: 基础编辑 → 列表 → **行操作** → 自定义按钮

### 按钮功能对照表

| 按钮 | UEditor命令 | 功能描述 | 实现方式 |
|------|-------------|----------|----------|
| `insertrow` | `insertrow` | 在当前行**前**插入空行 | UEditor内置 |
| `deleterow` | `deleterow` | 删除当前行 | UEditor内置 |
| `insertnextrow` | `insertrownext` | 在当前行**后**插入空行 | 已注册但不在工具栏 |

   - 9个Playwright测试确保核心功能不退化
   - 手动测试和自动化测试互补

### 改进建议

1. **前端配置优先级需明确文档**
   - UEditor的三层配置（全局/实例/组件）需要文档说明
   - 避免后续开发者困惑

2. **自定义按钮注册时机需统一**

   - 建议：按需注册，不用的不注册

3. **测试数据准备需自动化**

   - 建议：提供测试数据初始化脚本

4. **监控告警需要完善**
   - 生产部署后需要实时监控
   - 建议：集成日志分析和告警系统

### 避免的陷阱

1. **❌ 只看功能不看实现**
   - insertnextrow注册了，但没用，容易误判
   - **正确做法**: 既看注册代码，也看工具栏配置

2. **❌ 猜测旧系统行为**
   - 旧系统行为需要逐行验证，不能靠经验推测
   - **正确做法**: 读旧系统源码，逐行对比

   - 修改配置文件后需要重启服务和清缓存
   - **正确做法**: 完整的验证流程（重启→清缓存→测试→保存）

   - 0.1人日修复，0.4人日写文档，比例4:1
