## 1. 工具栏概览

Para设计器工具栏提供了16个编辑按钮，帮助您高效编辑Para元素内容。

### 1.1 工具栏布局

```
┌─────────────────────────────────────────────────────────────┐
│ [撤销] [重做] | [加粗] [斜体] [删除线] [上标] [下标] |       │
│ [有序列表] [无序列表] | [插入行] [删除行] |                  │
│ [定义列表] [内部引用] [DM引用] [图符]                        │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 按钮分组

| 分组 | 按钮 | 功能描述 |
|------|------|----------|
| **编辑操作** | 撤销、重做 | 撤销/重做最近的编辑操作 |
| **文本格式** | 加粗、斜体、删除线 | 设置文本样式 |
| **上下标** | 上标、下标 | 设置上标/下标（如化学式H₂O） |
| **列表** | 有序列表、无序列表 | 插入编号列表或项目符号列表 |
| **表格行操作** | **插入行、删除行** | **管理定义列表表格的行（v2.1.0新增）** |
| **S1000D元素** | 定义列表、内部引用、DM引用、图符 | 插入S1000D标准元素 |

## 2. 新增功能

### 2.1 插入行（insertrow）

#### 功能说明

在定义列表表格的当前行**前**插入一个空行。

#### 图标

![insertrow图标](./images/insertrow-icon.png)

#### 适用场景

- 在表格中间添加新的术语-定义对
- 调整表格结构
- 补充遗漏的内容

#### 使用步骤

1. **选择位置**：点击您想要在其前面插入新行的那一行
2. **点击按钮**：点击工具栏的"插入行"按钮
3. **填写内容**：在新插入的空行中输入内容
4. **保存**：编辑完成后点击"保存"按钮

#### 示例

**操作前**：
```
| 术语A | 定义A |
| 术语B | 定义B |  ← 选中这一行
| 术语C | 定义C |
```

**点击"插入行"后**：
```
| 术语A | 定义A |
| 术语B | 定义B |
| [空行] | [空行] |  ← 新插入的行（在B和C之间）
| 术语C | 定义C |
```

**填写内容后**：
```
| 术语A | 定义A |
| 术语B | 定义B |
| 新术语 | 新定义 |  ← 填写的新内容
| 术语C | 定义C |
```

### 2.2 删除行（deleterow）

#### 功能说明

删除定义列表表格中当前选中的行。

#### 图标

![deleterow图标](./images/deleterow-icon.png)

#### 适用场景

- 删除错误或不需要的术语-定义对
- 精简表格内容
- 清理重复数据

#### 使用步骤

1. **选择目标**：点击您想要删除的那一行
2. **点击按钮**：点击工具栏的"删除行"按钮
3. **确认删除**：该行立即被删除
4. **保存**：编辑完成后点击"保存"按钮

#### 示例

**操作前**：
```
| 术语A | 定义A |
| 术语B | 定义B |  ← 选中这一行并删除
| 术语C | 定义C |
```

**点击"删除行"后**：
```
| 术语A | 定义A |
| 术语C | 定义C |  ← 术语B已被删除
```

#### ⚠️ 重要提示

- **删除操作在保存前可撤销**：点击"撤销"按钮即可恢复
- **保存后无法恢复**：请在删除前确认不再需要该行数据
- **建议操作**：删除重要数据前，先备份整个DM文件

## 3. 使用场景

### 3.1 场景一：维护技术术语表

**需求**：在技术手册中添加新的缩略语解释

**步骤**：
1. 打开包含术语表的Para元素
2. 找到合适的位置（例如，按字母顺序插入"API"术语）
3. 点击"API"应该出现的后一行（如"ATC"所在行）
4. 点击"插入行"按钮
5. 在新行中填写：
   - 术语列：`API`
   - 定义列：`Application Programming Interface，应用程序编程接口`
6. 点击"保存"

### 3.2 场景二：更新故障代码表

**需求**：删除已废弃的故障代码

**步骤**：
1. 打开包含故障代码表的Para元素
2. 找到需要删除的故障代码行
3. 点击该行
4. 点击"删除行"按钮
5. 确认删除正确
6. 点击"保存"

### 3.3 场景三：批量调整表格结构

**需求**：在现有表格中间插入5个新的术语

**步骤**：
1. 打开Para元素
2. 定位到插入位置
3. 连续点击"插入行"按钮5次（或每插入一行填写一个术语）
4. 在5个新行中分别填写术语和定义
5. 点击"保存"

**技巧**：可以先插入所有空行，再逐行填写内容；也可以每插入一行就填写一行。

## 4. 操作指南

### 4.1 创建定义列表表格

在使用"插入行"和"删除行"按钮之前，您需要先创建一个定义列表表格。

**步骤**：
1. 打开Para设计器
2. 点击工具栏的"定义列表"按钮（在"删除行"按钮右侧）
3. 系统会自动插入一个5行2列的表格
4. 表格结构：
   - 左列：术语列（较窄）
   - 右列：定义列（较宽）

**默认表格示例**：
```
┌──────────┬────────────────────────┐
│ [术语]   │ [定义]                 │
├──────────┼────────────────────────┤
│          │                        │
├──────────┼────────────────────────┤
│          │                        │
├──────────┼────────────────────────┤
│          │                        │
├──────────┼────────────────────────┤
│          │                        │
├──────────┼────────────────────────┤
│          │                        │
└──────────┴────────────────────────┘
```

### 4.2 编辑表格内容

**填写单元格**：
1. 点击单元格
2. 直接输入文字
3. 支持复制粘贴（Ctrl+C / Ctrl+V）

**格式化文本**：
- **加粗**：选中文字 → 点击"加粗"按钮
- **上标**：选中文字 → 点击"上标"按钮（如H₂O中的2）
- **下标**：选中文字 → 点击"下标"按钮

### 4.3 调整表格行数

#### 增加行数

**方法1：逐行插入**
- 点击任意行 → 点击"插入行" → 重复操作

**方法2：批量插入**
- 快速连续点击"插入行"按钮多次

#### 减少行数

**方法1：逐行删除**
- 点击要删除的行 → 点击"删除行" → 重复操作

**方法2：批量删除**
- 快速连续点击"删除行"按钮多次

### 4.4 表格操作技巧

#### 技巧1：在表格开头插入

**需求**：在第1行之前添加新行

**步骤**：
1. 点击第1行
2. 点击"插入行"
3. 新行会出现在第1行位置，原第1行下移

#### 技巧2：在表格末尾添加

**需求**：在表格最后追加新行

**步骤**：
1. 点击最后1行
2. 点击"插入行"
3. 新行会出现在最后1行之前

**注意**：如果需要在表格最后追加，建议先插入，然后将最后1行的内容移到新行。

#### 技巧3：撤销误操作

**场景**：不小心删除了重要的行

**解决**：
1. 立即点击"撤销"按钮（在工具栏最左侧）
2. 或按快捷键 `Ctrl+Z`
3. 删除的行会被恢复

**⚠️ 重要**：撤销只在保存前有效，保存后无法撤销！

#### 技巧4：重复操作

**场景**：需要连续插入多行

**方法**：
- **单击模式**：每次点击"插入行"插入1行
- **快速模式**：快速连续点击，可以短时间插入多行

## 5. 注意事项

### 5.1 使用限制

| 限制项 | 说明 |
|--------|------|
| **适用表格** | 仅适用于definitionList（定义列表）表格 |
| **不适用** | 普通HTML表格不支持（Para元素中不允许普通表格） |
| **最小行数** | 建议保留至少1行，删除到0行可能导致表格消失 |
| **操作范围** | 只能在当前打开的Para元素中操作 |

### 5.2 保存前确认

在点击"保存"按钮前，请确认：

- ✅ 插入的行内容已填写完整
- ✅ 删除的行确认不再需要
- ✅ 表格结构符合预期
- ✅ 使用"撤销"按钮测试过（确保可以撤销）

### 5.3 数据安全

**重要提示**：

1. **保存前备份**
   - 对于重要DM，建议在大量修改前先导出备份
   - 使用"历史版本"功能查看和恢复历史版本

2. **删除前确认**
   - 删除操作保存后无法恢复
   - 建议截图保存重要数据

3. **测试环境**
   - 在测试环境中熟悉操作后再在生产环境使用
   - 可以创建测试DM进行练习

### 5.4 性能考虑

- **大表格操作**：如果表格超过100行，批量插入/删除可能需要几秒时间
- **建议分批**：一次性操作不超过50行，操作完成后保存，再继续下一批
- **避免频繁保存**：编辑过程中不需要频繁保存，完成一个章节后统一保存

## 6. 常见问题

### Q1: 为什么点击"插入行"没有反应？

**可能原因**：
1. 没有先创建定义列表表格
2. 光标不在表格内
3. 浏览器缓存问题

**解决方案**：
1. 先点击"定义列表"按钮创建表格
2. 点击表格内的任意行
3. 清除浏览器缓存（Ctrl+Shift+R）后重试

---

### Q2: 新行插入到了错误的位置怎么办？

**解决方案**：
1. 立即点击"撤销"按钮（Ctrl+Z）
2. 重新点击正确的行
3. 再次点击"插入行"

---

### Q3: 删除行后能恢复吗？

**回答**：
- **保存前**：可以通过"撤销"按钮（Ctrl+Z）恢复
- **保存后**：无法通过撤销恢复，但可以通过"历史版本"功能查看和恢复之前的版本

**建议**：
- 删除重要数据前先截图或导出备份
- 使用"历史版本"功能定期备份

---

### Q4: 可以一次插入多行吗？

**回答**：
- 不支持一次性插入指定数量的行
- 需要手动连续点击"插入行"按钮

**技巧**：
- 快速连续点击可以短时间插入多行
- 建议每插入5-10行就保存一次

---

### Q5: 表格最多可以有多少行？

**回答**：
- 理论上没有行数限制
- 实际建议：单个definitionList表格不超过100行
- 原因：行数过多会影响编辑性能

**建议**：
- 如果术语超过100个，考虑拆分成多个Para元素
- 或使用多个定义列表表格

---

### Q6: 删除最后一行会怎样？

**回答**：
- 如果表格只剩1行，删除后表格会消失
- 建议至少保留1行

**如果误删**：
- 立即点击"撤销"按钮恢复
- 或重新创建定义列表表格

---

### Q7: 能调整列宽吗？

**回答**：
- 定义列表表格的列宽是预设的（术语列30%，定义列70%）
- 目前不支持手动调整列宽
- 列宽会根据窗口大小自动调整

---

### Q8: 支持合并单元格吗？

**回答**：
- definitionList表格不支持合并单元格
- 这是S1000D标准的要求
- 如需复杂表格，请使用captionGroup（面板组）

---

### Q9: 能复制整行吗？

**回答**：
- 目前不支持整行复制粘贴
- 可以通过以下方式实现：
  1. 插入新行
  2. 复制源行的术语列内容 → 粘贴到新行术语列
  3. 复制源行的定义列内容 → 粘贴到新行定义列

---

### Q10: 更新后为什么看不到新按钮？

**可能原因**：
- 浏览器缓存未清除

**解决方案**：
1. 按 `Ctrl+Shift+R` 强制刷新
2. 或按 `Ctrl+Shift+Delete` 清除缓存后重新打开
3. 如仍未显示，联系技术支持

## 7. 快捷键参考

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| **撤销** | `Ctrl+Z` | 撤销最近的操作 |
| **重做** | `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做被撤销的操作 |
| **保存** | `Ctrl+S` | 保存当前Para内容 |
| **加粗** | `Ctrl+B` | 加粗选中的文字 |
| **全选** | `Ctrl+A` | 选中全部内容 |
| **复制** | `Ctrl+C` | 复制选中的内容 |
| **粘贴** | `Ctrl+V` | 粘贴内容 |
| **剪切** | `Ctrl+X` | 剪切选中的内容 |

**注意**：插入行和删除行目前没有快捷键，需要点击工具栏按钮。

## 8. 最佳实践

### 8.1 术语表维护

**建议结构**：
```
| 缩略语 | 完整形式 + 中文解释 |
├────────┼─────────────────────┤
| API    | Application Programming Interface，应用程序编程接口 |
| CPU    | Central Processing Unit，中央处理器 |
| RAM    | Random Access Memory，随机存取存储器 |
```

**维护技巧**：
- 按字母顺序排列，便于查找
- 定期审查和更新过时的术语
- 删除重复或废弃的术语

### 8.2 故障代码表

**建议结构**：
```
| 代码   | 故障描述 | 处理方法 |
├────────┼──────────┼──────────┤
| E001   | 传感器故障 | 检查传感器连接 |
| E002   | 温度过高 | 检查散热系统 |
```

**维护技巧**：
- 按代码编号顺序排列
- 添加新故障代码时使用"插入行"保持顺序
- 定期删除已解决的历史故障代码

### 8.3 规格参数表

**建议结构**：
```
| 参数名称 | 标准值 | 允许范围 |
├──────────┼────────┼──────────┤
| 电压     | 220V   | 200-240V |
| 频率     | 50Hz   | 48-52Hz  |
```

**维护技巧**：
- 分组管理（电气参数、机械参数等）
- 参数变更时使用"插入行"添加新版本
- 保留历史版本以便追溯
