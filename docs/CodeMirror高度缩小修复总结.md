# CodeMirror高度缩小问题修复总结

**问题**: 从设计视图切换回源码视图时，CodeMirror高度缩小，**刷新浏览器后才能恢复**  
**修复日期**: 2026-09-23  
**修复状态**: ✅ 已完成并编译通过

---

## 🔴 **问题根因**

### 核心发现

**关键线索**: "刷新浏览器后才能恢复" → 这是**CSS样式污染问题**，不是时序问题！

### 污染源：UEditor

UEditor在初始化和运行期间会：
1. **修改父容器的内联样式**（如 `height`、`overflow`、`position`）
2. 这些样式污染在UEditor销毁后**没有被清理**
3. 导致 `.design-view-container` 和 `.view-tabs` 保留了错误的样式
4. 切换回源码视图后，CodeMirror所在容器高度异常
5. **只有刷新浏览器才能恢复**（因为重新加载清除了污染）

---

## 🛠️ **修复方案**

### 双重防护策略

**策略A**: ParaDesigner销毁时清理污染（主防护）  
**策略B**: 视图切换时强制清理污染（备用防护）

### 修复1：ParaDesigner清理污染

**文件**: `ParaDesigner.vue:109-145`

清理父容器被UEditor污染的内联样式：
- `.design-view-container`
- `.view-tabs`

### 修复2：视图切换时清理污染

**文件**: `DmContentEditor.vue:748-778` + `492-523`

在切换到源码视图时，主动清理可能被污染的容器样式。
