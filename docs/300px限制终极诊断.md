# 300px限制问题 - 最终诊断

## 🔴 **问题确认**

经过所有修复尝试，问题依然存在：
- `scroll高度: 350px` 
- `clientHeight: 300px`

**这说明污染源不在内联样式，而在CSS规则或CodeMirror内部状态！**

## 🎯 **终极诊断脚本**

请在浏览器控制台依次运行：

### 脚本1：检查CSS规则

```javascript
// 查找所有影响CodeMirror-scroll的CSS规则
const cmScroll = document.querySelector('.CodeMirror-scroll');
const styles = window.getComputedStyle(cmScroll);

console.log('==== CodeMirror-scroll计算样式 ====');
console.log('height:', styles.height);
console.log('min-height:', styles.minHeight);
console.log('max-height:', styles.maxHeight);
console.log('overflow:', styles.overflow);

// 查找应用的CSS规则
const sheets = document.styleSheets;
const rules = [];
for (let sheet of sheets) {
  try {
    for (let rule of sheet.cssRules || sheet.rules) {
      if (rule.selectorText && rule.selectorText.includes('CodeMirror-scroll')) {
        rules.push({
          selector: rule.selectorText,
          cssText: rule.style.cssText,
          href: sheet.href
        });
      }
    }
  } catch (e) {
    // 跨域CSS跳过
  }
}
console.log('==== 影响CodeMirror-scroll的CSS规则 ====');
console.table(rules);
```

## 🛠️ **可能的终极解决方案**

基于300px/350px这个精确数值，我怀疑是：

### 可能性1：UEditor在window/document上添加了全局样式

```javascript
// 检查
console.log('body上的style:', document.body.style.cssText);
console.log('html上的style:', document.documentElement.style.cssText);
```

### 可能性2：CodeMirror的setSize被某处调用

```javascript
// 拦截setSize调用
const editor = document.querySelector('.dm-editor-page').__vue__.$refs.editor.getEditor();
const originalSetSize = editor.setSize;
editor.setSize = function(width, height) {
  console.warn('[拦截] setSize被调用:', width, height);
  console.trace();
  return originalSetSize.call(this, width, height);
};
```

### 可能性3：需要销毁并重建CodeMirror

如果以上方法都无法找到污染源，最后的方案是在切换时完全销毁并重建CodeMirror实例：

```javascript
// 在onViewTabChange中
if (this.$refs.editor) {
  // 保存当前状态
  const cm = this.$refs.editor.getEditor();
  const content = cm.getValue();
  const cursor = cm.getCursor();
  
  // 销毁旧实例
  cm.toTextArea();
  
  // 重建实例
  this.$nextTick(() => {
    this.$refs.editor.mounted();  // 重新初始化
    
    this.$nextTick(() => {
      const newCm = this.$refs.editor.getEditor();
      newCm.setValue(content);
      newCm.setCursor(cursor);
    });
  });
}
```
