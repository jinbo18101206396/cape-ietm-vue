### 问题2：保存后para前内容消失 🔴 → ✅

**严重程度**: P0 - 数据丢失  
**文件**: `ParaDesigner.vue:365-369`

**❌ 修复前**：
```javascript
this.editor.replaceRange(
  xml,
  { line: this.lineno, ch: 0 },
  { line: this.endline + 1, ch: 0 }  // ❌ 多删除一行！
)
```

**✅ 修复后**：
```javascript
this.editor.replaceRange(
  xml,
  { line: this.lineno, ch: 0 },
  { line: this.endline, ch: this.editor.getLine(this.endline).length }  // ✅ 精确到行尾
)
```

**修复说明**：
- `this.endline` = `</para>` 所在行号
- 修复前：删除到 `endline+1` 行首 → **误删下一行内容**
- 修复后：精确删除到 `endline` 行尾 → **只替换para元素**

**影响**：
- 修复前：保存会导致para后的元素被删除（数据永久丢失）
- 修复后：只替换当前para，其他内容安全

---

### 问题3：保存后未自动返回源码视图 🔴 → ✅

**严重程度**: P1 - 体验问题  
**文件**: `DmContentEditor.vue:492-495`

**❌ 修复前**：
```javascript
onParaSave() {
  this.dirty = true
  this.doSave()  // ❌ 只保存，停留在设计视图
}
```

**✅ 修复后**：
```javascript
async onParaSave() {
  this.dirty = true
  await this.doSave()

  // ✅ 保存成功后，自动切换回源码视图
  this.viewMode = 'source'
  this.paraDesignerVisible = false
  this.treeVisible = true
  if (!this.readonly) {
    this.attrVisible = true
  }

  // 强制刷新CodeMirror高度
  this.$nextTick(() => {
    if (this.$refs.editor && this.$refs.editor.getEditor()) {
      this.$refs.editor.getEditor().refresh()
    }
  })
}
```

**修复说明**：
- 保存成功后自动切换回源码视图（对标旧系统行为）
- 恢复左侧树和右侧属性面板显示
- 调用 `cm.refresh()` 确保高度正常（同时解决问题1）
