## 🚀 **测试执行指南**

### 前提条件

```bash
# 安装依赖
npm install

# 安装测试依赖
npm install --save-dev @vue/test-utils jest @playwright/test
```

### 执行单元测试

```bash
# 运行所有单元测试
npm run test:unit

# 运行ParaDesigner测试
npm run test:unit tests/unit/ParaDesigner.spec.js

# 运行DmContentEditor测试
npm run test:unit tests/unit/DmContentEditor.spec.js

# 查看覆盖率
npm run test:unit -- --coverage
```

### 执行E2E测试

```bash
# 启动前端开发服务器
npm run serve

# 另一个终端：运行E2E测试
npx playwright test tests/e2e/design-view-regression.spec.js

# 运行特定测试
npx playwright test -g "E2E-01"

# 调试模式
npx playwright test --debug

# 生成HTML报告
npx playwright show-report
```
