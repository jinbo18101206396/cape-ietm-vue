### 4.1 前置条件

3. 准备测试账号
   - 用户名: admin
   - 密码: admin123
   - 权限: DM编辑权限

### 4.2 测试执行流程

#### Step 1: 工具栏显示验证（5分钟）

1. 登录系统
2. 进入DM管理页面
3. 点击任意DM的"编辑"按钮
4. 在CodeMirror中找到一个`<para>`标签，双击打开Para设计器
5. 检查工具栏按钮：
   - [ ] 第10-11个按钮是insertrow和deleterow
   - [ ] insertrow图标：![insertrow icon]
   - [ ] deleterow图标：![deleterow icon]
   - [ ] 没有inserttable按钮
   - [ ] 鼠标悬停显示正确的tooltip

#### Step 2: insertrow功能验证（10分钟）

1. 点击"定义列表"按钮，创建一个5行的表格
2. 在第2行的第1列输入"术语2"，第2列输入"定义2"
3. 在第3行的第1列输入"术语3"，第2列输入"定义3"
4. 点击第3行（包含"术语3"的行）
5. 点击insertrow按钮
6. **预期结果**:
   - [ ] 在"术语3"行前插入了一个空行
   - [ ] 新行成为第3行，"术语3"下移到第4行
   - [ ] 总行数变为6行
7. 在新插入的第3行填写"新术语"和"新定义"
8. 点击"保存"按钮
9. **预期结果**:
   - [ ] 显示"保存成功"提示
   - [ ] 关闭Para设计器
   - [ ] CodeMirror中XML包含6个`<definitionListItem>`
   - [ ] 第3个`<definitionListItem>`包含"新术语"和"新定义"

#### Step 3: deleterow功能验证（10分钟）

1. 打开刚才保存的para（应该有6行）
2. 点击第3行（包含"新术语"的行）
3. 点击deleterow按钮
4. **预期结果**:
   - [ ] "新术语"行被删除
   - [ ] "术语3"行上移到第3行
   - [ ] 总行数变为5行
5. 点击"保存"按钮
6. **预期结果**:
   - [ ] 显示"保存成功"提示
   - [ ] CodeMirror中XML包含5个`<definitionListItem>`
   - [ ] 第3个`<definitionListItem>`包含"术语3"和"定义3"（不是"新术语"）

#### Step 4: 边界场景验证（10分钟）

1. **场景1: 在第1行前插入**
   - 点击第1行
   - 点击insertrow
   - [ ] 在第1行前插入空行，原第1行下移

2. **场景2: 删除到只剩1行**
   - 连续点击deleterow 4次（删除到只剩1行）
   - [ ] 表格仍存在（只剩1行）或表格被删除

3. **场景3: 撤销操作**
   - 重新创建5行表格
   - 点击insertrow插入1行
   - 点击Undo按钮
   - [ ] 插入的行被撤销，恢复到5行

#### Step 5: 兼容性验证（10分钟）

1. **验证其他按钮不受影响**
   - [ ] undo/redo按钮正常
   - [ ] bold/superscript/subscript按钮正常
   - [ ] 有序/无序列表按钮正常
   - [ ] deflist按钮正常
   - [ ] interrefbutton按钮正常
   - [ ] dmrefbutton按钮正常
   - [ ] symbolbutton按钮正常

2. **验证不影响普通表格删除逻辑**
   - 复制一个`<table>`标签到para中
   - 保存
   - [ ] 普通table被删除（符合预期）
   - [ ] 只保留definitionList表格
