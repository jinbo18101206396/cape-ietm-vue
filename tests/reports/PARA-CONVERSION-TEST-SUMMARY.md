## 🐛 发现并修复的Bug

### Bug #1: thead标签错误匹配 (P1级)

**严重程度**: 🔴 P1 (高优先级)  
**状态**: ✅ **已修复并验证**

#### 问题
正则表达式`/<th[^>]*>/`会错误匹配`<thead>`标签：
```javascript
// ❌ 错误代码
.replace(/<th[^>]*>/g, '<entry>')

// 导致：<thead> → <entry> (错误)
```

#### 修复
```javascript
// ✅ 修复后
.replace(/<th(\s[^>]*)?\>/g, '<entry>')

// 确保：<th> → <entry> ✅
//       <thead> → 保持 ✅
```

#### 验证
- ✅ TC-04单元测试通过
- ✅ 输出结构符合S1000D标准
- ✅ 无回归影响

**详细分析**: 见 `para-thead-bug-fix.md` (7,000字)

## 🎓 经验教训

### 问题根源
1. **正则表达式过于宽泛**: `[^>]*`可能匹配标签名的一部分
2. **缺少词边界检查**: 未区分`<th>`和`<thead>`
3. **测试覆盖不足**: 之前未测试带thead的表格

### 预防措施
1. **正则审查**: 所有标签替换必须使用词边界
2. **单元测试**: 表格转换必须覆盖thead/tbody/caption等变体
3. **代码审查**: HTML标签替换的正则必须防止误匹配

### 最佳实践
```javascript
// ❌ 错误：可能误匹配相似标签
.replace(/<th[^>]*>/g, '<entry>')

// ✅ 正确：词边界保护
.replace(/<th(\s[^>]*)?\>/g, '<entry>')

// ✅ 正确：负向前瞻
.replace(/<th(?!ead)[^>]*>/g, '<entry>')
```
