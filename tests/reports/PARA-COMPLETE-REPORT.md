## 💡 **经验总结**

### 这个Bug的教训
1. **初始值很重要**: `endline: -1` 看似无害，实则是定时炸弹
2. **边界条件检查**: 不要假设变量一定会被正确设置
3. **隐藏字符危险**: `\n` 这种字符肉眼不可见，但危害巨大
4. **防御性编程**: 宁可抛出错误，也不要静默删除数据

### 推荐的最佳实践
```javascript
// ❌ 不好：假设变量有效
editor.getLine(this.endline)

// ✅ 好：验证后再使用
if (this.endline < 0 || this.endline >= editor.lineCount()) {
  throw new Error('Invalid endline')
}
editor.getLine(this.endline)
```
