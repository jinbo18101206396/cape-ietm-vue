# 历史版本列表只显示最新版本问题分析

## 问题描述
用户反馈：查看历史版本页面的列表中，为何只显示最新版本数据？为啥不显示历史版本数据？

## 问题根本原因分析

### 可能原因1：数据本身只有一个版本 ⭐⭐⭐⭐⭐（最可能）

**现象**：数据库中该DM确实只有一个版本记录

**验证方法**：
```sql
SELECT id, sns, info_code, info_code_variant, issue_no, in_work, 
       is_latest, version_type, dmc_code, create_time
FROM ietm_data_module
WHERE status = '1'
  AND sns = 'YOUR_SNS'
  AND info_code = 'YOUR_INFO_CODE'
ORDER BY issue_no DESC, in_work DESC;
```

**如果查询结果只有1条**：
- 说明该DM从未发布过新版本
- 这不是BUG，而是业务现实

### 可能原因2：onlyPublished被勾选 ⭐⭐⭐

**现象**：前端"仅显示发布版本"复选框被勾选，且只有最新版本是发布版本

**验证方法**：
1. 检查UI上的复选框状态
2. 取消勾选后，看是否显示更多版本

**数据验证**：
```sql
SELECT issue_no, in_work, version_type, is_latest
FROM ietm_data_module
WHERE status = '1'
  AND sns = 'YOUR_SNS'
  AND info_code = 'YOUR_INFO_CODE'
ORDER BY issue_no DESC, in_work DESC;
```

如果有多条记录，但只有一条 `version_type='1'`（发布版本），则勾选"仅显示发布版本"时只会显示一条。

### 可能原因3：infoCodeVariant匹配问题 ⭐⭐

**现象**：数据库中 `info_code_variant` 字段为空字符串，但查询时传了 `NULL`（或相反）

**SQL判断逻辑**：
```sql
AND (info_code_variant = #{infoCodeVariant}
     OR (info_code_variant IS NULL AND #{infoCodeVariant} IS NULL))
```

这个逻辑处理了 NULL 匹配，但没有处理空字符串 `''` 的情况。

**潜在问题**：
- 数据库中: `info_code_variant = ''` (空字符串)
- 查询传参: `infoCodeVariant = null`
- 结果: 不匹配

**验证方法**：
```sql
-- 检查是否有空字符串
SELECT DISTINCT info_code_variant, 
       CASE WHEN info_code_variant IS NULL THEN 'NULL'
            WHEN info_code_variant = '' THEN 'EMPTY_STRING'
            ELSE 'HAS_VALUE' END AS variant_type
FROM ietm_data_module
WHERE status = '1'
  AND sns = 'YOUR_SNS'
  AND info_code = 'YOUR_INFO_CODE';
```

### 可能原因4：用户看错了表格 ⭐

**现象**：表格实际有多行，但用户只注意到第一行（最新版本）

**验证方法**：
- 检查表格滚动条
- 检查分页信息
- 查看 `dataSource.length`

## 排查步骤

### 步骤1：确认数据库中是否有多个版本

在DM8数据库中执行：

```sql
-- 查询某个DM的所有版本
SELECT 
    id,
    dmc_code,
    issue_no || '-' || in_work AS version,
    is_latest,
    version_type,
    create_time
FROM ietm_data_module
WHERE status = '1'
  AND sns = (SELECT sns FROM ietm_data_module WHERE status = '1' AND ROWNUM = 1)
  AND info_code = (SELECT info_code FROM ietm_data_module WHERE status = '1' AND ROWNUM = 1)
ORDER BY issue_no DESC, in_work DESC;
```

## 结论

根据代码审查，**后端查询逻辑完全正确**，没有任何会导致只返回最新版本的过滤条件。

**最可能的原因是**：
1. **数据库中该DM确实只有一个版本**（90%概率）
2. **前端"仅显示发布版本"被勾选**（8%概率）
3. **infoCodeVariant空字符串vs NULL匹配问题**（2%概率）

## 建议修复方案

### 如果是原因1（数据只有1个版本）
✅ 这不是BUG，无需修复

用户可以通过以下方式创建历史版本：
- 对DM进行编辑并发布新版本
- 系统会保留旧版本作为历史版本

### 如果是原因3（空字符串匹配问题）
修改SQL查询条件：

```sql
AND (info_code_variant = #{infoCodeVariant}
     OR (info_code_variant IS NULL AND #{infoCodeVariant} IS NULL)
     OR (info_code_variant = '' AND (#{infoCodeVariant} IS NULL OR #{infoCodeVariant} = ''))
     OR (info_code_variant IS NULL AND #{infoCodeVariant} = ''))
```

或者在Service层统一处理空字符串：

```java
// 将空字符串统一转为null
if (infoCodeVariant != null && infoCodeVariant.trim().isEmpty()) {
    infoCodeVariant = null;
}
```
