## ⚠️  发现的潜在问题

### 问题1: 历史版本查询条件可能不完整

**当前查询条件** (`IetmDataModuleMapper.xml:175-191`):
```sql
WHERE status = '1'
  AND sns = #{sns}
  AND info_code = #{infoCode}
  -- ...
```

**潜在问题**:
- 发布操作将版本的 `status` 改为 `'2'`
- 如果查询条件只包含 `status='1'`，则**已发布的版本不会显示在历史版本列表中**

**验证方法**:
1. 创建一个DM
2. 发布该DM（`status='1'` → `'2'`）
3. 查看历史版本列表
4. **检查是否能看到已发布的版本**

**建议修复**:
```sql
WHERE status IN ('1', '2')  -- 包含草稿和已发布
  AND sns = #{sns}
  AND info_code = #{infoCode}
  -- ...
```
