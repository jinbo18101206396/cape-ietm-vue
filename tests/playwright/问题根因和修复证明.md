# 历史版本只显示最新版本问题 - 根因和修复证明

## 问题现象

**用户反馈**：查看历史版本页面的列表中，为何只显示最新版本数据？为啥不显示历史版本数据？

## 根本原因（已确认）

### 原因1：签入操作会归档原版本 ⭐⭐⭐⭐⭐

**问题代码位置**：`IetmDataModuleServiceImpl.java` 第556-580行（修复前）

**错误逻辑**：
```java
public boolean checkIn(String id, String username, String comment) {
    // ... 前面的代码 ...
    
    // 🚨 问题代码：签入时将原版本归档
    if (oConvertUtils.isNotEmpty(dm.getCheckoutDmId())) {
        String originalDmId = dm.getCheckoutDmId();
        IetmDataModule originalDm = this.getById(originalDmId);
        if (originalDm != null) {
            // ❌ 错误：将原版本归档，status从'1'改为'0'
            this.update(new LambdaUpdateWrapper<IetmDataModule>()
                    .eq(IetmDataModule::getId, originalDmId)
                    .set(IetmDataModule::getStatus, "0")  // 归档
            );
        }
    }
}
```

**为什么会导致只显示最新版本？**

1. 用户创建DM → `001-00` (status=1)
2. 用户签出 → `001-00` (status=1, is_latest=0) + `001-01` (status=1, is_latest=1)
3. 用户签入 → **系统将 `001-00` 的 status 改为 0** ❌
4. 查询历史版本：`WHERE status='1'` → 只返回 `001-01`

**每次签入都会归档原版本，所以历史版本列表永远只有最新的1个版本！**

---

### 原因2：查询条件不包含已发布版本 ⭐⭐⭐

**问题代码位置**：`IetmDataModuleMapper.xml` 第182行（修复前）

**错误SQL**：
```sql
SELECT * FROM ietm_data_module
WHERE status = '1'  -- ❌ 只查询草稿状态
  AND sns = #{sns}
  AND info_code = #{infoCode}
```

**为什么会漏掉已发布版本？**

- 发布操作会将 status 改为 '2'
- 查询条件只包含 status='1'，所以已发布版本查询不到

---

## 修复方案（已实施）

### 修复1：删除签入时的归档逻辑

**修改文件**：`IetmDataModuleServiceImpl.java:556-563`

**修复代码**：
```java
public boolean checkIn(String id, String username, String comment) {
    // ... 前面的代码 ...
    
    // ✅ 修复：签入时保留原版本作为历史版本
    if (oConvertUtils.isNotEmpty(dm.getCheckoutDmId())) {
        String originalDmId = dm.getCheckoutDmId();
        log.info("签入成功，原版本ID：{} 保留为历史版本 (is_latest='0', status='1')", originalDmId);
        // 不再归档，保留 status='1'
    }
}
```

**为什么这样修复是安全的？**

签出时已经归档了更早的历史版本（第418-433行），避免了唯一约束冲突：
```java
// 签出时的代码（无需修改）
LambdaUpdateWrapper<IetmDataModule> archiveWrapper = new LambdaUpdateWrapper<IetmDataModule>()
        .eq(IetmDataModule::getIsLatest, "0")  // 只归档历史版本
        .ne(IetmDataModule::getId, originalDm.getId())  // 排除当前版本
        .set(IetmDataModule::getStatus, "0");  // 归档
this.update(archiveWrapper);
```

所以签入时无需再归档原版本。
