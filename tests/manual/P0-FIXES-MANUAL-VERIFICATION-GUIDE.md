## 🔍 快速检查命令

**检查para标签配对**:
```javascript
// 在浏览器Console中执行
const xml = document.querySelector('.CodeMirror').CodeMirror.getValue()
const openCount = (xml.match(/<para[^>]*>/g) || []).length
const closeCount = (xml.match(/<\/para>/g) || []).length
console.log('para开始标签:', openCount)
console.log('para结束标签:', closeCount)
console.log('是否配对:', openCount === closeCount ? '✅' : '❌')
```

**检查嵌套para**:
```javascript
const xml = document.querySelector('.CodeMirror').CodeMirror.getValue()
const hasNested = /<para[^>]*>\s*<para[^>]*>/.test(xml)
console.log('是否有嵌套para:', hasNested ? '❌ 有' : '✅ 无')
```
