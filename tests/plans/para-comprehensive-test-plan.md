### 🎯 关键发现

#### 1. **循环替换死锁风险** (R-01, R-02) 🔴
```javascript
// paraConverter.js Line 146-148
para = para.replace(/<sup/g, '<superScript')  // ❌ 危险！
  .replace(/<sub/g, '<subScript')             // ❌ 危险！

// 问题：
// 输入: <sup>text</sup>
// 步骤1: <sup/g → <superScript  结果: <superScriptt>text</sup>
// 步骤2: 再次执行时，<superScript 又匹配 <sup，导致无限循环！
```

**根因**: `<sup` 会匹配 `<superScript` 的开头，导致：
- HTML→XML时：`<sup>` → `<superScript>` → `<superScriptcript>` → ...（死循环）
- XML→HTML时：`<superScript>` → `<sup>` → 正确，但下次转换又出错

#### 2. **XML结构破坏** (R-03) 🔴
```javascript
// paraConverter.js Line 141
para = para.replace(/<p.*?>/g, '<p>')  // ❌ 会匹配 <para>

// 问题：
// 输入: <para>内容</para>
// 输出: <p>内容</para>  // 标签不匹配！
```

#### 3. **定义列表中的thead误匹配** (R-06) 🔴
```javascript
// paraConverter.js Line 183 (deflist转换)
.replace(/<th.*?>/g, '<listItemTerm>')  // ❌ 会误匹配 <thead>

// 我们已修复Line 540的S1000D table转换
// 但Line 183的deflist转换仍存在相同问题！
```
