# 公式ICN预览修复 - 手动验证清单

## 修复信息
- **修复日期**: 2026-10-16
- **修复文件**: `DmPreviewModal.vue:282-348`
- **问题**: 源码视图插入公式ICN后点击"浏览"，公式图片显示"ICN加载失败"
- **根因**: 公式ICN存储在数据库BLOB，但预览统一使用磁盘文件加载端点
