## 🐛 常见问题排查

### 问题1: 控制台仍显示"找到 0 个ICN"

**原因**: 浏览器缓存未清除  
**解决**: 
1. 按 `Ctrl+Shift+Delete` 清除缓存
2. 或按 `Ctrl+F5` 强制刷新
3. 或使用无痕模式

### 问题2: 图片显示损坏图标

**原因**: 后端ICN资源不存在或Token过期  
**解决**:
1. 检查Network标签，查看 `/ietm/icn/view/ICN-xxx` 请求状态
2. 如果返回401，重新登录
3. 如果返回404，检查数据库中是否有该ICN记录

### 问题3: 控制台无日志输出

**原因**: Console过滤设置或日志级别  
**解决**:
1. 确保Console显示所有级别（不要只显示Errors）
2. 清除Console过滤条件
3. 刷新页面重新触发

## 💡 技术说明

### 修复的本质

**修复前的错误判断**:
```javascript
// ❌ 错误：通过onclick判断
return !img.hasAttribute('onclick')
```

**修复后的正确判断**:
```javascript
// ✅ 正确：通过src判断
const src = img.getAttribute('src') || ''
const isMultimediaPlaceholder = src.includes('.gif') || src.includes('avicit/')
return !isMultimediaPlaceholder
```

### 为什么这样修复？

1. **`<graphic>` 标签生成的图片**：
   - class: `figureLinkGraphic`
   - src: `ShowSmallImage`（占位值）
   - onclick: `showMultimediaInfo('ICN-xxx')`
   - **需要加载**: ✅

2. **`<multimediaObject>` 生成的占位图标**：
   - src: `avicit/ietm/viewer/images/audio.gif`
   - onclick: `showMultimediaInfo('ICN-xxx')`
   - **跳过加载**: ✅（已是最终图标）

**关键区别**：不在onclick，而在src的值！
